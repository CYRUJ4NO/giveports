# giveports
Herramienta para extraer puertos de salidas de NMAP tipo -oN y -oG
# uso
giveports <salidaNmap.txt>

## Instalación

Para instalar `giveports` de forma global en tu sistema GNU/Linux o macOS, ejecuta los siguientes comandos:

```bash
# Clonar el repositorio
git clone https://github.com/CYRUJ4NO/giveports.git

# Acceder a la carpeta del proyecto
cd giveports

# Dar permisos de ejecución al instalador
chmod +x install.sh

# Ejecutar la instalación
sudo ./install.sh
